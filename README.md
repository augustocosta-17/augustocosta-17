## 🙋‍♂️ Sobre mim

- 🤖 No meu trabalho atual, desenvolvo **agentes de IA** com a biblioteca **Agno** e **automações RPA** que tiram tarefas repetitivas das mãos das pessoas.
- 🌐 Também construo **plataformas web completas**, do banco de dados ao deploy em produção.
- 📊 Minha base vem da área de **dados**: Python, SQL, BigQuery e Google Cloud.

---

## 🚀 O que venho construindo

- **Agentes de IA com Agno**: agentes que usam ferramentas e dados para executar tarefas de negócio.
- **Automações RPA**: robôs que executam processos manuais de forma confiável e sem intervenção.
- **Plataforma para personal trainers e alunos**: treinos, avaliações físicas, cobrança via Pix, notificações push, comunidade e app instalável (PWA).
- **Sistema de gestão para escola técnica**: site institucional, funil de matrículas em Kanban, turmas, diário docente e central de atendimento que reúne WhatsApp e Instagram.
- **Deploy e operação**: aplicações em Docker numa VPS, com CI/CD no GitHub Actions, migrações automáticas e volta para a versão anterior se algo falhar.
